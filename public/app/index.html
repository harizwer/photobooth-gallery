Canon DSLR over USB, plugged into the tabletNot connected

Connect the Canon EOS 750D to the tablet with a USB cable (USB-C OTG adapter), turn the camera on, then tap Connect camera on the tablet. The booth uses the camera's live view for the preview and takes full-quality photos with the DSLR. Set the camera to JPEG (not RAW).

Best: the Photobooth Android app — it talks to the Canon directly, so the live view is smooth and stable. Download the app (APK) on the tablet, open it, and log in as usual. In Chrome the Canon also works, but its live view is less reliable. Does not work on iPad.

Printer

The DNP DS-RX1HS is connected to this laptop with USB. Prints from the tablet come out here.
Prints start by themselves while this page is open, even behind other windows. Keep the laptop awake (no sleep) during the event.
⚡ Automatic printing (no Print button)Not checked yet
A website cannot skip the print window by itself: the browser has to be opened in printing mode. This file does it for you on Windows:
  1. Make the DNP the default printer in Windows (Settings → Printers; turn off “Let Windows manage my default printer”), with the paper set to 4×6.
  2. Download the file below and double-click it. Put it on the desktop for every event.
  3. It opens this page in its own window. Log in once, choose Admin, turn on “This laptop prints”.
Works with Chrome or Edge. That window prints straight to the DNP, and keeps working when it is behind other windows.
Print size & position (this laptop)
Do this once so strips get cut: open Chrome normally, press Ctrl + P on any page, choose DNP DS-RX1HS, open More settings and set Paper size to the DNP 6x4 size with the 2 inch cut (it may be called “(6x4)x2”, “6x4 2inch cut” or “PC 4x6 Cut”), Margins: None, Scale: Default, then print. Chrome remembers this and uses it for every photobooth print.
The alignment test prints a border and the cut line. If the cut is not on the dashed line or the border is uneven, adjust Move right / Move down (negative numbers move left / up) and test again.
For printing without the print window, start Chrome on this laptop with this command (once, from a desktop shortcut). Set the DNP as the default printer and paper size 4x6 (PC) in its driver.
Download laptop setup (Windows)
Double-click the downloaded file on this laptop. It sets the DNP as the default printer, makes the “Photobooth Printer” shortcut, keeps the laptop awake, and opens the DNP settings for the 2-inch cut. If Windows says “Windows protected your PC”, tap More info → Run anyway.
