# Photobooth Gallery

Public online gallery for Photobooth Studio events, served by GitHub Pages.

- Event gallery: `https://harizwer.github.io/photobooth-gallery/?e=<event id>`
- One guest's photo (booth QR code): `...?e=<event id>&p=<photo id>`

Photos are stored in Supabase Storage and uploaded by the booth laptop. This page only reads them with the public (publishable) key.
